# Betme

A social predictive market: users post predictions, others stake YES/NO with
play-money credits, and accurate predictors earn a larger share of the pool.
Also includes per-prediction chat, direct messaging with video messages, user
following, and earned badges.

## Cursor Cloud specific instructions

### Stack & services
- Single service: a **Next.js 15 (App Router)** app (frontend + API routes in one process). TypeScript, Tailwind CSS, Prisma 6, SQLite. No external databases/caches required.
- Run the dev server with `npm run dev` (http://localhost:3000). Scripts live in `package.json`.

### Database (SQLite via Prisma)
- `DATABASE_URL` is set in the committed `.env` (`file:./dev.db`, not a secret).
- `prisma/dev.db` is git-ignored, so a fresh checkout has no database. Create/sync it with `npm run db:push`. The update script does this automatically on VM startup.
- `npm run db:seed` loads demo data (users `nova`, `kai`, `zoe`; sample markets; a seeded video message). **It wipes all existing rows first** — don't run it if you want to keep local data. `npm run db:reset` = force-reset schema + reseed.
- The Prisma client is generated by the `postinstall` hook; after changing `prisma/schema.prisma`, run `npm run db:push` (regenerates client + syncs schema).

### Auth model
- Lightweight cookie session, no passwords: entering any username in the top nav logs you in and creates the user on first use (`/api/auth/login`).

### Lint / test / build (see `package.json` scripts)
- `npm run lint`, `npm test` (Vitest), `npm run build`.
- **Do not upgrade the linter toolchain.** ESLint is pinned to v8 with `eslint-config-next@15` to match Next 15. ESLint 9 flat config + `eslint-config-next@16` breaks `next lint` with a "Converting circular structure to JSON" error. Keep these versions aligned with the installed Next version.

### Gotchas
- **Prisma is pinned to v6.** Prisma 7 removed `url` from the datasource block and requires a `prisma.config.ts` + driver adapters; do not bump to 7 without that migration.
- Video-message uploads are written to `public/uploads/` (git-ignored). The seeded video message references the committed clip `public/samples/welcome.mp4`. Browser video *recording* needs camera access (unavailable in headless test browsers) — use the "Upload a video file" fallback or the seeded clip to exercise playback.
- Global CSS import types come from `src/types/global.d.ts` (`declare module "*.css"`), because Next's bundled types only declare `*.module.css`.
